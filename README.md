## 🚀 Projetos em destaque

### 🎮 IFAM GameHub

Plataforma web para gerenciamento e integração de jogos, usuários e rankings.

O projeto centraliza os dados dos jogadores e permite acompanhar o desempenho entre diferentes jogos através de um sistema compartilhado de pontuações e rankings.

**Principais funcionalidades:**

* Cadastro e autenticação de usuários
* Sistema de salvamento de dados
* Dashboard do jogador
* Rankings e estatísticas
* Compartilhamento de pontuações entre jogos
* Configurações e personalização
* Desenvolvimento dos próprios jogos integrados à plataforma

**Tecnologias:** HTML5 · CSS3 · JavaScript · Bootstrap · Firebase

**Status:** ✅ Finalizado

### 🧊 Voxel Procedural Engine

Projeto de estudo voltado à **geração procedural de mundos tridimensionais voxel**, desenvolvido na Unity com C#.

O objetivo é construir uma base capaz de gerar mundos 3D procedurais de forma otimizada e interativa, explorando técnicas de representação, geração e renderização de grandes ambientes.

**Sistemas desenvolvidos:**

* Sistema de divisão do mundo em **chunks**
* **Face Culling** para redução de geometria desnecessária
* Geração procedural de terrenos
* Texturização através de **Texture Atlas**
* Suporte a diferentes texturas por face
* Sistema de **render distance**
* Estruturação dos dados e da renderização do mundo

**Tecnologias:** Unity · C#

**Status:** 🚧 Em desenvolvimento

### Monitoramento de poluentes atmosféricos para áreas de riscos de Manacapuru-AM

Participação em projeto de iniciação científica voltado ao desenvolvimento de um sistema de **baixo custo para monitoramento de poluentes atmosféricos e detecção de focos de queimadas**.
